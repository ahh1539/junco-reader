Junco Reader vs Kokoro Web

Both are free, ad-free, browser-based readers built on the same open-source Kokoro-82M voice model. The difference is mostly in how you get text in, and how fast you hear anything at all.

  Junco Reader kokoroweb.app
Cost Free, no ads Free, no ads
Voice before any download Yes -- only browser voices reported as local; no download No -- the ~326 MB Kokoro model must download first
Neural voice engine Kokoro-82M (fetches model/runtime assets, then synthesizes in this browser) Kokoro-82M (on-device)
File formats PDF, TXT, Markdown, pasted text Pasted or typed text (no file upload, as far as we can tell)
Documents leave your device Junco does not upload or persist document contents Never
Installable (PWA) Yes Not offered as far as we can tell
Companion app Junco for iPhone -- newsletters as a daily podcast None

Where Kokoro Web is ahead

It runs in more languages beyond English on its site, and its blog covers the technical side of browser TTS in more depth. If you just want to paste a short passage and are happy to wait out the model download once, it's a clean, focused tool.

Where Junco Reader is ahead

You can drop in a PDF or Markdown file, not just paste text -- and if you don't want to wait on the model download, Junco Reader's Instant tier uses only a browser voice reported as local, with zero download and no gate to clear first. Junco Reader is also installable as an app, and it's built by the team behind Junco, an iPhone app that reads your email newsletters aloud every morning with the same voice family.

Try it yourself -- drop in a PDF or paste an article. Instant uses only a local-reported browser voice; Natural fetches model assets then synthesizes in this browser.
